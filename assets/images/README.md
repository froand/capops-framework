# Images

This directory is reserved for original, appropriately licensed image assets. The initial framework uses Mermaid diagrams embedded in Markdown instead of presentation images.

For a future asset, record its purpose, creator or public source, license, and accessible text description in the same change. Do not upload presentation screenshots, source archives, customer architectures, logos implying endorsement, or third-party diagrams without suitable rights.

The diagram source is maintained with the page it explains. No binary images are required to understand the framework.
