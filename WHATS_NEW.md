# What's new

This log records meaningful changes to the proposed CapOps community framework. It does not announce provider features or capacity availability.

## 2026-09-15 - Initial public documentation

The initial documentation expands a compact framework baseline into a practical learning path:

- One canonical definition, ten explained principles, five domains, twelve detailed capabilities, ten personas, and a nine-step iterative lifecycle.
- Decision-focused operating reviews and federated accountability, with maturity evidence across thirteen dimensions at five levels.
- Ten implementation guides, ten Markdown table templates, and ten fictional business scenarios.
- Four dated provider mappings, separating quota, discounts, capacity mechanisms, supported scope, and residual risk.
- Seven original Mermaid diagrams with equivalent prose, version-aligned rendering, keyboard-focusable horizontal scrolling on narrow screens, searchable MkDocs Material navigation, copyable code, and community policies.
- Reproducible source, link, anchor, generated-site, Markdown, YAML, and diagram checks, plus a default-branch Pages workflow.

The presentation's useful concepts were editorially transformed; source files, speaker notes, private analysis, and presentation artwork are not distributed. See [VALIDATION.md](VALIDATION.md) for actual checks and their limits.

The public repository is [froand/capops-framework](https://github.com/froand/capops-framework), with documentation published on [GitHub Pages](https://froand.github.io/capops-framework/). The initial hosted build and deployment succeeded, and live browser checks verified search, clipboard copying, diagrams, and mobile behavior. Nine repository topics, eight requested labels, and private vulnerability reporting are configured.
